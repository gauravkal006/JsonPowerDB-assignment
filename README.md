# JsonPowerDB Internship

This repository contains the assignments and projects I worked on during my JsonPowerDB internship at Login2Xplore.

During this internship, I learned how to use JsonPowerDB, work with REST APIs, and connect HTML forms to a database using JavaScript.

## Modules

The repository contains work from four modules.

### Module 1
Introduction to JsonPowerDB and basic database concepts. This module covers JSON data, database operations, and getting familiar with JsonPowerDB.

### Module 2
Worked on an Employee Registration Form using HTML, JavaScript, and JsonPowerDB. The form is used to enter employee details and save them in the database.

### Module 3
Practiced JsonPowerDB commands such as PUT, PUT_ALL, UPDATE, REMOVE, GET_BY_KEY, and GET_BY_RECORD.

Also worked on an Employee Form and a Student Enrollment Management System.

The Student Enrollment project supports:
- Adding new student records
- Searching students using Roll Number
- Updating student details
- Deleting student records
- Resetting the form

### Module 4
Contains the assignments and practical work for the fourth module.

## Student Enrollment Project

The Student Enrollment Management System is a simple web application developed using HTML, CSS, JavaScript, and JsonPowerDB.

It stores student details such as Roll Number, Full Name, Class, Birth Date, Address, and Enrollment Date.

**Database:** SCHOOL-DB  
**Relation:** STUDENT-TABLE

The project uses JsonPowerDB REST APIs to perform CRUD operations.

## Benefits of JsonPowerDB

- Easy to work with JSON data
- Supports REST API operations
- No need to write SQL queries for basic operations
- Supports indexed data retrieval
- Can be integrated with JavaScript applications

## How to Run

1. Clone or download this repository.
2. Open the required project folder in VS Code.
3. Add a valid JsonPowerDB connection token in the configuration file.
4. Open `index.html` using Live Server.
5. Test the form and database operations.

Note: Browser requests require the JsonPowerDB API to allow cross-origin access.
